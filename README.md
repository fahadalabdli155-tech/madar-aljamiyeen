# مدار الجامعيين

الموقع التعريفي لمبادرة **مدار الجامعيين** — مجتمع ممارسة يجمع الممارسين والخبراء العاملين مع الشباب الجامعي في جدة.

موقع ثابت (Static) بالكامل: صفحة واحدة بلا خادم ولا قاعدة بيانات ولا خطوة بناء (build). يكفي فتح `index.html` في المتصفح لتشغيله.

---

## بنية الملفات

```
index.html              الصفحة كاملة (كل النصوص والمحتوى هنا)
assets/
  css/styles.css        كل التنسيقات والحركات
  js/main.js            الشريط العلوي، القوائم، العدادات، الشبكة المتحركة
  img/team/             صور فريق العمل
  fonts/                خط "The Year of The Camel" (خط العناوين)
```

## التشغيل محليًا

افتح `index.html` مباشرة بالمتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
```

ثم افتح <http://localhost:8000>

---

## النشر (مجانًا عبر GitHub Pages)

1. من صفحة المستودع على GitHub اذهب إلى **Settings ← Pages**
2. تحت **Source** اختر **Deploy from a branch**
3. اختر الفرع `master` والمجلد `/ (root)` ثم **Save**
4. انتظر دقيقة أو دقيقتين — يظهر رابط الموقع أعلى الصفحة نفسها

بعد ذلك، **أي تعديل تحفظه على الفرع `master` يُنشر تلقائيًا** خلال دقيقة تقريبًا.

> إذا لم تظهر التعديلات فورًا في المتصفح، فغالبًا السبب النسخة المخزّنة (cache).
> حدّث الصفحة تحديثًا قسريًا: `Ctrl+Shift+R` على ويندوز أو `Cmd+Shift+R` على ماك.

## تعديلات شائعة

### تغيير نص

كل النصوص موجودة في `index.html`. ابحث عن النص المراد تغييره وعدّله مباشرة.

### إضافة عضو جديد لفريق العمل

1. ضع صورته في `assets/img/team/` (يُفضّل صورة مربّعة، مثلًا 800×800)
2. في `index.html` ابحث عن `<!-- ============ TEAM ============ -->`
3. انسخ إحدى بطاقات `team-card` وعدّل الاسم والدور والنبذة ومسار الصورة:

```html
<div class="team-card reveal" style="--i:2">
  <div class="team-avatar team-avatar--photo">
    <img src="assets/img/team/اسم-الملف.jpg" alt="اسم العضو" loading="lazy">
  </div>
  <h3>اسم العضو</h3>
  <span class="role">الدور</span>
  <p>نبذة مختصرة.</p>
</div>
```

قيمة `--i` تحدّد ترتيب ظهور البطاقة في الحركة (0، 1، 2 ...).

**عضو بدون صورة؟** استبدل كتلة `team-avatar--photo` بالحروف الأولى من اسمه:

```html
<div class="team-avatar">م.س</div>
```

### تعديل أرقام المؤشرات

في `index.html` ابحث عن `stat-tile`. الرقم في الخاصية `data-count` (العدّاد يتحرك تلقائيًا إليه)، ونسبة امتلاء الشريط في `data-fill`.

### تغيير الألوان

في أول `assets/css/styles.css` ضمن `:root` — الكحلي `--navy-*` والذهبي `--gold-*`.
تعديل هذه القيم يغيّر الموقع كله، في الوضعين النهاري والليلي معًا.

## ملاحظات

- الموقع يدعم **الوضع الليلي والنهاري** تلقائيًا حسب إعداد الجهاز، مع إمكانية التبديل يدويًا من زر الشمس/القمر.
- الحركات والتأثيرات تتعطّل تلقائيًا لمن يفعّل خيار **تقليل الحركة** (Reduce Motion) في نظامه، ولا تعمل تأثيرات المؤشر على أجهزة اللمس.
- الملف `.vercelignore` مخصّص لمن يرغب باستضافة الموقع على Vercel بدلًا من GitHub Pages. وجوده لا يؤثّر على النشر عبر GitHub Pages.
